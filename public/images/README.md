# Imagens do acervo SOLARTE

Este diretório contém os arquivos reais enviados pelo usuário ao repositório: **14 PNGs, com 13 conteúdos únicos**. São 8 pinturas, 1 detalhe de pintura, 3 fotografias do artista e 1 fotografia do ateliê. O arquivo `detalhe-composicao-religiosa-copia.png` é uma cópia idêntica de `detalhe-composicao-religiosa.png`, preservada sem duplicar a obra na galeria.

Os arquivos foram renomeados para identificação, mantendo os bytes originais. O mapeamento completo, dimensões, classificação e destinos estão em `docs/image-integration.md`; os hashes SHA-256 e nomes de origem estão em `data/image-inventory.json`.

A autorização registrada é a instrução do usuário para uso desses arquivos no site SOLARTE, não uma licença pública inferida. Não há imagem documental com biografia impressa entre os arquivos recebidos; o retrato de camisa branca é uma fotografia independente.

Para adicionar material autorizado, salve o original aqui e use `/images/nome-do-arquivo.ext` nos dados. Informe largura e altura em pixels, texto alternativo, procedência e autorização. Preserve assinaturas, proporções, enquadramento e cores. `next/image` produz versões otimizadas sem modificar o original. Os nomes descritivos não substituem títulos ou outros metadados desconhecidos das obras.
