# Imagens autorizadas do acervo SOLARTE

Nenhuma das 13 imagens citadas no pedido estava disponível nesta atualização. Este diretório não contém pinturas nem fotografias simuladas.

Ao receber os arquivos, preserve os originais (incluindo assinaturas e enquadramento) e salve-os aqui com nomes descritivos. Utilize os caminhos `/images/nome-do-arquivo.ext` nos dados. Next Image produz variantes otimizadas sem modificar os originais.

Papéis esperados: retrato pintado da mulher de cabelos castanhos (hero), pinturas geométricas e figurativas, artista sorrindo com boina e óculos (home), fotografia do ateliê, artista de camisa branca (O Artista), retrato formal com óculos e vestimenta escura (O Artista).
